A program that writes an original two-line warning to a past self to /output/entry.txt: don't eat the last slice of pizza at 2 a.m. on 14 March 2019 in Tom's kitchen — that slice caused food poisoning on the morning of a first proper job interview, and missing it is why the writer ended up in the career they actually liked.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
